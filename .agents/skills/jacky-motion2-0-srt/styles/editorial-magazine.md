# 杂志信息图风 (editorial-magazine)

适用：深度观点、方法论、人物故事、文化商业洞察、研究解读。
气质：高级中文编辑特稿，一页正在重排的杂志跨页。重点是版面秩序，不是好看的背景。
记忆钩子：超大衬线断句 + 编号压版 + 拉引切入。

## 视觉不变量

1. **色**：纸白底 + 编辑红 `--accent`；青绿 `--accent-2` 只做对照标记。同屏最多一个强强调色。
2. **字**：衬线负责观点重量（主标题 96-156px、900 字重），无衬线负责标签注释。编号可放大到 120px+ 作版面锚点。
3. **构图**：非对称跨页网格、强页边、大留白。衬线大标题/编号/拉引/细分隔线/裁切图像至少出现两种。标题与图像/编号共享一条明显轴线。留白是编辑判断，不是极简装饰。
4. **运动**：版面平移、图像裁切、标题分层、编号推进。文字按编辑层级出现（栏目→标题→引用→注释），不是同一种 fade。

## 签名组件（assets/styles/editorial-magazine.css）

`.ed-num`（描边巨号）· `.pq`/`.pq-bar`/`.pq-text`（拉引）· `.ed-rule-thick`（粗规则线）· `.crop`（观点性裁切，仅氛围图；信息截图用 `.shot`）· `.hl`/`.hl-teal`（划线强调）

## 版式偏好

优先 L01 概念揭示（跨页大标题）/ L05 纵向层级（编号推进）/ L03 左右对照 / L02 收束定格（金句+来源）。
推荐 recipe：claim-lockup / split-reveal / stack-expand。

## 风格禁忌

1. 卡片堆叠泛滥、密集流程线、中心辐射图。
2. 科技渐变、随机氛围图背景、复古滤镜装饰花纹——杂志感靠网格断行编号引用裁切成立。
3. 长段正文、全居中排版、PPT 式 bullet。
4. 没有裁切/版面动作的静态图片展示。
5. 瑞士海报式无衬线巨字 + 蓝黄高反差。
