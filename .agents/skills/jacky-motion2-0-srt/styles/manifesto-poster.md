# 宣言式大字报风 (manifesto-poster)

适用：观点输出、行业判断、认知冲击型内容、"我不同意"类反共识表达。
气质：现代主义宣言海报。观点即视觉，没有装饰的位置。
记忆钩子：900 字重巨字断言 + 墨块反白 + 一种信号红。

## 视觉不变量

1. **色**：米白底 + 墨黑 + 信号红 `--accent` 全片唯一强调色。禁 IKB 蓝/柠檬黄/点阵网格——那是归藏瑞士风的语言，本风格是宣言海报不是网格系统。
2. **字**：Noto Sans SC 900 巨字（hero 128-200px）+ Archivo Black 数字/序号。字号对比 ≥6:1。
3. **构图**：直角、4px 厚规则线、色块分区。一屏一句断言；留白大胆偏置（左重右空/上重下空），制造海报张力。
4. **运动**：果断、利落、快（--dur-base 0.65s）。字块砸落、色块推开、规则线划出。没有柔和渐显——宣言不需要温柔。

## 签名组件（assets/styles/manifesto-poster.css）

`.ink-block`（墨块反白，全片 1-2 次）· `.red-block`（红块断言）· `.mf-num`（描边巨号，`.solid` 红实心）· `.mf-line`（粗底线断言行）· `.hl`（红字）· `.hl-inverse`（红底反白词）

## 运动个性提示

本风格的高级感在"重量"：大字用 `expo.out` + 从 y:40 砸落，落地稳；色块用 scaleX/scaleY 从轴线推出（transform-origin 设在推出方向）；强调词红底反白用一次 `back.out(2)` 盖章。全片节奏像敲钉子，一下是一下。

## 版式偏好

优先 L01 概念揭示（整屏断言）/ L03 左右对比（旧共识 vs 我的判断）/ L05 纵向层级（三条论据）/ L02 收束定格。
推荐 recipe：claim-lockup / split-reveal / stack-expand。

## 风格禁忌

1. 圆角、阴影、渐变、毛玻璃——直角纯色到底。
2. 第二种强调色；红色大面积铺满超过 1/3 屏。
3. 小字堆砌解释——宣言页正文每屏 ≤2 短句，说不完的进口播。
4. 瑞士网格点阵、Helvetica 巨字海报组合（归藏语言）；包豪斯几何装饰图形堆砌。
5. 弹跳、旋转、柔焦——宣言的动作只有"砸、推、划、章"。
