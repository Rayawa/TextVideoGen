# 暖纸墨蓝框架手稿风 (ink-framework)

适用：方法论、认知框架、哲学思辨、系统性深度拆解、"一张图讲清 X"类内容。
气质：一份被认真排印过的思想文稿（kami / Anthropic 纸感语言）。框架图在纸上安静展开。
记忆钩子：暖羊皮纸 + 墨蓝勾线节点 + 衬线定调 + 书卷级慢节奏。

## 视觉不变量

1. **色**：暖羊皮纸底 + 墨蓝 `--accent` 勾线与断句 + 赭红 `--accent-2` 仅作极少量批注。每屏强调只选其一。
2. **字**：衬线（Noto Serif SC）负责标题与结论的思想重量，无衬线正文，等宽做编号与元信息。
3. **构图**：框架图/思维导图/概念地图是主角——细线节点盒 + 细连线 + 大页边。层级靠线宽和底色区分（core 节点墨蓝反白）。留白是书页的呼吸。
4. **运动**：安静、缓慢（--dur-slow 1.6s）。连线描线生长、节点依次落位、概念让位展开。没有弹跳，没有过冲——思想不着急。

## 签名组件（assets/styles/ink-framework.css）

`.node-box`（概念节点，`.core` 墨蓝反白）· `.ink-index`（细线圆编号）· `.ink-frame`（双线标题框，全片限 1-2 次）· `.ink-svg`（连线规范 1.5px）· `.hl`（墨蓝断句）· `.hl-note`（赭红批注）

## 运动个性提示

这是"框架生长"风格：核心节点先立，连线用 stroke-dashoffset 缓缓画出，子节点在线到达后落位。关键结论前的悬停（≥450ms）在本风格里可以更长——留白即敬意。

## 版式偏好

优先 L05 纵向层级 / L10 核心外扩（思维导图）/ L04 横向流程（推理链）/ L01 概念揭示 / L02 收束定格。
推荐 recipe：stack-expand / concept-expand / path-build / claim-lockup。

## 风格禁忌

1. 密集数据、KPI 大屏、涨跌行情——那是 finance 的领域。
2. 粗黑巨字、高饱和强调、任何"热闹"的东西。
3. 节点盒里塞长段文字（节点只放概念词 + 一行说明）。
4. 连线交叉穿字、径向超过 3 个外围节点。
5. 把纸感做成做旧滤镜——本风格的纸是干净的排印纸，不是档案旧纸（那是 newspaper-evidence）。
