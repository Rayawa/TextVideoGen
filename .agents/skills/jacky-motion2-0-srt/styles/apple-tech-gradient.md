# 苹果科技渐变演示风 (apple-tech-gradient)

适用：AI 工具、产品概念、抽象机制、keynote 式能力展示。
气质：克制的产品发布会。黑色空间里，一个概念被光场托起。
记忆钩子：空间层级光场 + 单一发光焦点。每段至少一次"概念从深色空间浮出、让位给结构、锁定关键词"。

## 视觉不变量

1. **色**：纯黑空间底 + 单一低强度暖光 + 热力橙 `--accent` 只给最终焦点。禁蓝紫渐变、彩虹光、离散光球阵。
2. **字**：干净无衬线、轻字重、强字号差。主概念词 120-180px（600 以内字重），副标题 28-42px，正文保持轻。
3. **构图**：一屏最多 1 个主视觉 + 1-3 个辅助模块；毛玻璃是空间图层不是卡片阵列；黑色留白是空间不是空洞（主概念周围留 18%-30% 呼吸区）。
4. **运动**：慢推、mask reveal、模块错层、空间让位。动态感来自空间层级，不来自密集卡片和霓虹闪烁。

## 签名组件（assets/styles/apple-tech-gradient.css）

`.card`/`.flow-node`（毛玻璃模块）· `.glass`（大玻璃面板）· `.glow-orb`（氛围光球，纯装饰放信息后方）· `.hl`（热力橙关键词）

## 版式偏好

优先 L01 概念揭示 / L04 横向流程 / L10 核心外扩 / L06（左题右阵玻璃网格）/ L09 截图展示。
推荐 recipe：claim-lockup / stack-expand / screenshot-annotation / concept-expand。

## 风格禁忌

1. 密集仪表盘、一屏 6+ 卡片、所有模块等大等亮。
2. 渐变当信息载体；氛围光盖住文字；毛玻璃背发光过亮。
3. 多个强调色同时出现；粗黑海报字。
4. 截图做低透明背景（必须放 `.glass`/`.card` 里清晰展示）。
5. 瑞士蓝/IKB/柠檬黄/点阵网格组合——那是归藏的语言。
