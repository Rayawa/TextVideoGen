# 报纸剪贴纪实风 (newspaper-evidence)

适用：新闻事件、历史、政策、案例拆解、证据链、调查复盘。
气质：证据、档案、纪录片。观众在跟随一组整理过的材料得出结论。
记忆钩子：证据编号 + 红色批注 + 纸面材质。先看到材料，再看到标注，最后看到被锁定的结论。

## 视觉不变量

1. **色**：黑/白/米色 + 红色批注 `--accent` 或黄色荧光 `--accent-2`；红黄不同时大面积使用。
2. **字**：衬线建立报纸/档案感（证据标题 64-110px、结论 88-132px），来源/日期/编号用等宽。
3. **构图**：主剪报最大，辅助证据错位叠放。每张剪报含来源/标题/日期/引用/编号中至少 2 个。纸张可轻微旋转，文字基线不能乱。纸面材质变化至少 2 种（撕边/胶带/错位阴影）。
4. **运动**：纸张滑入、镜头推近、标注划过、盖章锁定。证据按口播顺序逐个出现，不铺满全屏。

## 签名组件（assets/styles/newspaper-evidence.css）

`.clipping`（剪报，`.tilt-l/.tilt-r/.torn`）· `.tape`（胶带）· `.ev-num`（证据编号）· `.red-underline`/`.red-circle`（贴合式红批注）· `.hl`（黄荧光，只标 1-2 短语）· `.stamp`（印章结论）

## 版式偏好

优先 L08 证据板 / L09 截图标注 / L03 对照剪报（官方说法 vs 现实证据）/ L04（时间线推进）。
推荐 recipe：evidence-spotlight / screenshot-annotation / split-reveal。

## 风格禁忌

1. 干净矩形白卡冒充剪报；无来源的空白纸片。
2. 横跨半屏的大红框（标注必须贴合焦点：短线/小圈/短箭头）。
3. 整段涂黄；手绘装饰每屏 >3 个。
4. 一屏塞满碎剪报导致焦点消失（一屏 1 主证据 + 2-3 辅助）。
5. 假来源假日期假引用——没有真实材料必须标"示意"，不能冒充档案。
