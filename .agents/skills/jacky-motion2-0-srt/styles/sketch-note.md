# 手绘线稿讲解风 (sketch-note)

适用：科普讲解、概念拆解、教学内容、面向新手的亲切口吻视频。
气质：白纸黑线的知识手稿。老师边讲边在纸上画——亲切、聪明、零廉价感。
记忆钩子：楷体手写 + 不规则墨线框 + 一支红笔圈重点。

## 视觉不变量

1. **色**：暖白纸底 + 墨黑线稿 + 红笔 `--accent` 圈注；蓝笔 `--accent-2` 极少量。一屏最多一处红。
2. **字**：LXGW WenKai（霞鹜文楷）全场，标题靠字号和 700 字重拉开层级；铅笔灰做旁注。
3. **构图**：手绘框四角不对称（token 已内置），线可以微歪，但信息仍在明确 grid 上。极淡方格稿纸底纹是签名，不能换成横线本或纯白。
4. **运动**：**画出来，不是飞进来**——SVG 线稿描线（stroke-dashoffset）、下划线从左到右划过、红圈手绘式圈上、文字像写字一样 mask reveal。

## 签名组件（assets/styles/sketch-note.css）

`.card`/`.flow-node`（不规则墨线框）· `.ink-circle`（红笔圈注）· `.wavy`（波浪线）· `.pencil`（铅笔旁注）· `.hl`（荧光笔）· `.sketch-svg`（手绘 SVG 线稿规范：2.5-3px stroke、round cap）

## 运动个性提示

本风格最出效果的是 SVG 描线：概念图、箭头、圈注全部用 `gsap.from(path,{strokeDashoffset:L})` 画出来，时长 0.6-1s。卡片入场用小幅 y 位移即可，不做过冲——手稿是安静的。

## 版式偏好

优先 L05 纵向层级（概念展开）/ L04 横向流程（步骤图解）/ L10 核心外扩（思维导图式）/ L03 左右对比（误区 vs 正解）。
推荐 recipe：path-build / concept-expand / stack-expand / split-reveal。

## 风格禁忌

1. 精致投影、渐变、毛玻璃——纸上没有这些。
2. SVG 画人脸人物场景（AI 手画必翻车）；插图只画箭头、框、简单图形符号。
3. 手绘感过度：满屏乱线、所有元素都歪。歪是调味，不是主菜。
4. 用低质量"手写体涂鸦字"替代霞鹜文楷。
5. 截图和真实素材照常用 `.shot` 完整展示，不做手绘滤镜。
