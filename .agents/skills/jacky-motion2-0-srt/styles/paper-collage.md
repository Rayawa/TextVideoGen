# 小红书贴纸剪贴画报风 (paper-collage)

适用：生活方式、好物测评、经验分享、轻科普、种草/避坑清单——受众面最广的大众向内容。
气质：复古剪贴簿 × 新潮贴纸画报。像一页被认真贴出来的手账跨页，热闹但有秩序。
记忆钩子：厚描边贴纸卡 + 硬偏移阴影 + 胶带票据 + 马克笔划重点。

## 视觉不变量

1. **色**：牛皮纸暖底 + 珊瑚红 `--accent` 主强调 + 天蓝 `--accent-2` 少量点缀 + 奶油白贴纸。禁高饱和彩虹撞色——热闹感来自材质错落，不来自颜色数量。
2. **字**：ZCOOL KuaiLe 圆趣显示字负责标题与大数字，Noto Sans 负责正文，等宽负责票据脚注。
3. **构图**：纸片可以歪（±1.5° 以内），轴线不能乱——底层仍是明确 grid，同组贴纸统一尺寸节奏。每屏 1 张主贴纸显著大于其余。手绘批注（箭头/圈）每屏 ≤3 个且指向焦点。
4. **运动**：贴纸"啪"地落位（scale 微过冲 + 一次落定）、胶带按压、马克笔划过、票据抖出。像手账被贴出来，不是 UI 在动。
5. **标题标签**：`.kicker` 必须按文字内容收口，视觉宽度只等于文字宽度加水平内边距；禁止被 grid/flex 拉伸成横跨标题区的长条，也不得明显长于它所标注的标题短语。

## 签名组件（assets/styles/paper-collage.css）

`.sticker`（贴纸卡，`.tilt-l/.tilt-r/.pop`）· `.tape`/`.tape.warm`（胶带）· `.ticket`（虚线票据脚注）· `.kicker`（药丸贴纸标签）· `.hl`（黄色马克笔）· `.doodle`（手绘批注锚位）

## 运动个性提示

入场用 `back.out(1.6)` 的轻微过冲最出味（贴上去的感觉）；旋转角度直接写在 CSS 静止态，动画只做位移+缩放，避免转着飞入。

## 版式偏好

优先 L06 矩阵网格（贴纸阵）/ L03 左右对比（红黑榜/买前买后）/ L04 横向流程（步骤帖）/ L07 数据主屏（大数字贴纸）。
推荐 recipe：matrix-fill / split-reveal / path-build / claim-lockup。

## 风格禁忌

1. 干净扁平卡片（没有描边和硬阴影 = 不是贴纸）。
2. 旋转角度超过 2°、同屏所有纸片同角度倾斜（假手工感）。
3. Emoji 当图标；真实商品/界面截图必须放贴纸框里完整展示。
4. 粉紫渐变、荧光野蛮撞色。
5. 与 newspaper-evidence 混淆：本风格是明快画报，不做档案批注、不做撕纸做旧证据感。
