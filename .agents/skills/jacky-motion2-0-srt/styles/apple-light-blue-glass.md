# 苹果浅色蓝白产品演示风 (apple-light-blue-glass)

适用：AI 工具、SaaS 产品、App 功能讲解、工作流演示、需要录屏主轨和口播配合的轻科技内容。

## 风格不变量

1. 白色 / 极浅蓝空间底，蓝色焦点，轻毛玻璃层。整体像 Apple 官网产品页和 WWDC 功能演示，不是深色发布会。
2. 视觉中心必须是一个清晰的产品概念、界面截图、流程节点或功能结果；禁止只有抽象光效。
3. 留白是展示区和呼吸区，不是内容偏小。主视觉占注意力 45%-65%，辅助信息沿一条明确轴线排布。
4. 蓝色只用于焦点、当前状态、路径线和少量标签；禁止蓝紫渐变、霓虹粒子、彩虹光、金融大屏绿。
5. 毛玻璃用于分层和承载信息，不能堆成卡片墙；一屏最多 1 个主玻璃面板 + 1-3 个辅助模块。

## 签名组件（assets/styles/apple-light-blue-glass.css）

- `.soft-glass`：大面积轻玻璃面板，适合承载截图或核心结构。
- `.product-shot`：产品截图容器，完整清晰展示，不裁切信息。
- `.blue-chip`：小型蓝色状态标签，只标当前状态。
- `.focus-ring`：短时焦点环，贴合关键词或截图区域。
- `.spectrum-line`：浅蓝路径线，表达流程或能力展开。

## 推荐版式

- L01 概念揭示：白底大标题 + 一块轻玻璃主视觉。
- L03 左右对比：旧方式灰化，新方式用蓝色点亮。
- L04 横向流程：浅蓝路径线逐步生长。
- L09 产品截图展示：截图为主，解释在侧边轻层。
- L10 核心外扩：中心产品结果 + 最多 3 个能力模块。

## 禁忌

- 黑色发布会背景（那是 apple-tech-gradient）
- 蓝紫 / 紫粉渐变科技感
- 截图低透明当背景
- 四周空白中间小卡片
- 玻璃卡片堆叠超过 3 个
- 大面积纯蓝背景或高饱和霓虹光
