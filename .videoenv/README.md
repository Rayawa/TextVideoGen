# VideoTextGen isolated environment

This directory is the project-local equivalent of `.venv`. It contains pinned runtimes, all installed dependency trees under `deps/`, OpenCode auth/config/state, caches, models, browser binaries, FFmpeg/FFprobe links, logs, and temporary files. Source `activate` or use the launchers under `../bin/`. Rebuild it after cloning with `../bin/setup`.

Only `activate` and this document are source-controlled. Runtime contents are ignored.
